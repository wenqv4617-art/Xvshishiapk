### 网易云登录链路（Vercel 中转 https://netease-cloud-music-api-backup-eight-iota.vercel.app）
- 实测 curl 结论：
  - `/search`、`/register/anonimous`、`/captcha/sent` 均 HTTP 200 + code 200（连通/发码正常）。
  - `/login/cellphone` 业务失败（验证码错误）时返回 **HTTP 503 + body {code:503,msg:"验证码错误"}** —— NeteaseCloudMusicApi 业务错误用 503 状态码。
- 根因1：app_music.js 全部用 `res.ok`（HTTP 200）判断成功 → 业务失败 503 → 误报"API 连接失败"。
- 根因2：匿名注册返回的 cookie 是**字符串**（新版 API），旧代码用 `Array.isArray` 判断 → 永远拿不到匿名 cookie。
- 修复（app_music.js）：
  - 新增 `musicSystem.ncmRequest(url)`：解析 body，以 `body.code === 200` 判定成功（不依赖 HTTP 状态码）。
  - 新增 `musicSystem.extractNcmCookie()`：兼容字符串/数组 cookie。
  - 改造 7 处：checkNcmApiConnectivity / sendNcmCaptcha（含匿名注册）/ loginNcmByCaptcha（登录失败显示服务端真实 message）/ syncNcmByUid（user/playlist + playlist/track/all）/ syncNcmUserData（user/account）/ searchNcmMusic 通道二。
- 待办：用户提供验证码后 curl 实测登录 + 歌单同步全链路（用户手机号 19708895837）。注意网易云风控（滑块验证）可能导致登录 503。

- 验证码发送 ✓（/captcha/sent 200）；验证码本身有效（服务端正常处理）。
